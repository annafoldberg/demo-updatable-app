# Demo Updatable App
Demo console application used to demonstrate versioned release artifacts and client application updates in the distributed deployment management system.

---
## CI/CD Pipeline
The CI/CD pipeline builds and publishes the demo application as a versioned release artifact that can be retrieved and installed by the deployment management system.
